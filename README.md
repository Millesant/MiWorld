# NoWorld

NoWorld is a Minecraft world editor plugin for the Nukkit server. It's not like I made this plugin for you or anything, but it provides commands for world editing, such as setting and replacing blocks, and managing selections. The plugin uses a session-based system to track player actions and selections and includes undo and redo functionality for world editing operations. Hmph!

## Installation

Fine, I'll tell you how to install the NoWorld plugin on your Nukkit server, but don't think I'm doing this because I want to help you or anything!

1. Download the latest release of the NoWorld plugin from the [releases page](https://github.com/nollyakwastaken/NoWorld/releases). Not that I care if you do or not.
2. Copy the downloaded JAR file to the `plugins` directory of your Nukkit server. It's not like it's hard or anything.
3. Restart your Nukkit server to load the NoWorld plugin. Hmph, I guess you can handle that, right?

## Usage

I suppose I can explain how to use the NoWorld plugin's commands for world editing, but don't get the wrong idea!

### Commands

- `/editor help` - Shows the help message for the editor commands. Not that you need it or anything.
- `/editor selection[sel]` - Selection commands. It's not like it's complicated or anything.
- `/editor set <block id>` - Sets the block at the current selection. Hmph, you should know this already.
- `/editor replace <from block id> <to block id>` - Replaces the block at the current selection with the given block. Don't mess it up.
- `/editor undo` - Undoes the last operation. Not that you should need to use it.
- `/editor redo` - Redoes the last undone operation. Hmph, just don't make mistakes in the first place.

### Selection Commands

- `/editor selection[sel] help` - Shows the help message for the selection commands. Not that you need it or anything.
- `/editor selection[sel] point[p] first[f]` - Sets the first selection point. Hmph, it's not that hard.
- `/editor selection[sel] point[p] second[s]` - Sets the second selection point. Don't mess it up.
- `/editor selection[sel] clear[c]` - Clears the selection. Hmph, you should know this already.
